# Contributing

Thanks for helping out! Issues and pull requests are both welcome.

- **Game data:** every gate, time, location or story step needs a source, so
  we don't rely on anyone's memory of the games. Add it to the game's file in
  [sources/](sources/). If the sources disagree or don't settle it, add it to
  that file's Open questions instead.
- **Checks:** run `pnpm check` before you open a pull request, and
  `pnpm check:styles` if you changed any CSS.
- **Visual changes:** please include screenshots at phone width (390px) and
  desktop width.
- **Sign-off:** sign off your commits (`git commit -s`) to confirm you can
  share the change under the project's license
  ([Developer Certificate of Origin](https://developercertificate.org/)).
